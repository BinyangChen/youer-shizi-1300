# 幼儿识字小达人（1300 字测试）

一个**手机端、点开即玩**的幼儿识字测试小游戏。字库为《通用规范汉字表（2013）一级字表》前 1300 字，按笔画由易到难排序。

## 玩法
- 每页 10 个大字卡片，点卡片右上角勾选框标记「已认识」。
- 已勾选的字自动进入 **⭐ 我的字库**；未勾选的留在 **📝 待完成**。
- 进度保存在「本设备 + 本链接」的浏览器本地（localStorage），关掉再开记录还在；换设备/换浏览器不互通。
- 链接后加 `?book=数学` 等参数可生成**独立进度**的另一套字库。

## 本地运行
直接用浏览器打开 `index.html` 即可（单文件，字库已内嵌，无需联网、无需构建）。

## 文件说明
- `index.html` —— 单文件成品，可直接部署 / 打开。
- `chars.json` / `data.js` —— 1300 字字源数据。
- `lvl.txt` —— 字表原始来源（通用规范一级字表）。
